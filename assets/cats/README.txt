The sleeping cat (loader) and the walking cat (bottom bar) are drawn as
inline SVG directly in index.html, not as .gif files — this is how the
original site was built, and it keeps them crisp at any size with no
extra image requests. The paw prints are also inline SVG, generated by
js/cats.js.

This folder is here if you'd rather swap any of them for real image or
GIF assets later:
1. Save files here, e.g. walking-cat.gif, sleeping-cat.gif, paw.png.
2. Replace the matching inline <svg>...</svg> block in index.html with
   an <img src="assets/cats/your-file"> tag.
